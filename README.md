# Uptime Command — VPS Uptime Monitoring Dashboard

Premium, secure, self-hosted uptime dashboard for all your VPS across **EricHost, ServerBroker, Servica** and any other provider.
Pure PHP 8 (no Composer, no build step) — just `git pull` on cPanel and it runs.

## Features

- 🔐 **Secure login** — Argon2id/bcrypt hashes, rate-limit lockout (5 fails / 15 min per IP), CSRF on every form, strict CSP, session fingerprint + idle timeout, optional **2FA (Google Authenticator)**, optional **IP whitelist**, Telegram alert on every login
- 🗝 **Encrypted vault** — root passwords & provider panel logins encrypted with **AES-256-GCM**; viewing requires re-entering your password and is logged
- 📡 **Monitoring** — Smart check (SSH / 80 / 443 in parallel + ICMP fallback), TCP port, ICMP ping, HTTP(S). Parallel checks, false-alarm protection (mark down after N failures)
- ⏱ **Exact up/down durations** — “Up for 12d 4h”, “Down for 23m”, incidents with start/end/duration
- 📊 **One-click reports** — Today / Yesterday / 7d / 30d / month / custom: uptime %, downtime, incidents, longest outage, avg response → CSV, PDF (print), Telegram
- 🤖 **Telegram bot** — DOWN / RECOVERED alerts, “still down” reminders, daily report at your chosen time, login alerts
- 🏢 **Providers** — add any provider, colour badges, panel URL + encrypted login, per-provider health & monthly cost
- 📈 Response-time chart (24h), 90-day uptime bars, renewal reminders, activity/audit log

## Install on cPanel

1. **Create a database** — cPanel → *MySQL® Database Wizard* → create DB + user, grant **ALL PRIVILEGES**.
2. **Pull the code** — cPanel → *Git™ Version Control* → **Create**
   - Clone URL: `https://github.com/pandeydeepak2000/uptime.git`
   - Repository path: e.g. `/home/USER/public_html/uptime` (or the document root of a subdomain like `status.yourdomain.com`)
3. **Run the installer** — open `https://yourdomain.com/uptime/install.php`, fill DB details + admin user. (It locks itself afterwards.)
4. **Cron job** — cPanel → *Cron Jobs* → *Once Per Minute* `* * * * *`:
   ```
   /usr/local/bin/php /home/USER/public_html/uptime/cron.php >/dev/null 2>&1
   ```
   (exact command is shown in **Settings → Cron & system**)
5. **Telegram** — @BotFather → `/newbot` → copy token; get your chat ID from @userinfobot → paste in **Settings → Telegram alerts** → *Send test message*.
6. Enable **SSL** (AutoSSL) for the domain and turn on **2FA** in Settings → Security.

### Updating
cPanel → Git™ Version Control → Manage → **Pull or Deploy** → *Update from Remote*. Your `app/config.php` and data are never overwritten.

## Security notes

- `app/config.php` (generated by installer) contains the **encryption key** — back it up. Losing it means saved passwords can't be decrypted.
- `app/`, `storage/`, `.git` and sensitive file types are blocked by `.htaccess`.
- Locked out by IP whitelist? set `'disable_ip_whitelist' => true` in `app/config.php`.
- Behind Cloudflare? set `'trust_proxy' => true` so real visitor IPs are used.

## Requirements
PHP 8.0+ with PDO (MySQL or SQLite), OpenSSL, cURL. `exec()` is optional (enables ICMP ping).
